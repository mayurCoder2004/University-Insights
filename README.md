# University Insights - MBBS Abroad Website

A modern, responsive website designed to help students explore and apply for MBBS programs in various countries. This platform serves as a comprehensive resource for international medical education opportunities.

## 📋 Project Overview

University Insights is a dynamic web application that provides detailed information about MBBS programs across seven different countries. The platform features an intuitive interface with interactive elements, smooth animations, and comprehensive information about medical education opportunities abroad.

## 🌟 Key Features

### For Students
- Quick enquiry forms for immediate assistance
- Detailed country-wise information about MBBS programs
- Comprehensive eligibility criteria and admission process
- Student testimonials and success stories
- Interactive contact forms with country preference selection
- Real-time counseling request system

### Technical Features
- Responsive design that works across all devices
- Animated elements using AOS (Animate On Scroll) library
- Font Awesome integration for modern iconography
- Clean and semantic HTML5 structure
- Interactive testimonial carousel
- Form validation and submission handling

## 🛠️ Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Styling and responsive design
- **JavaScript** - Interactive features and animations
- **AOS Library** - Scroll-based animations
- **Font Awesome** - Icons and visual elements
- **CDN Integration** - External resource management

## 🚀 Setup and Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/university-insights.git
```

2. Navigate to the project directory:
```bash
cd university-insights
```

3. Open `index.html` in your preferred browser or set up a local server.
